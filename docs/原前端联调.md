# Next.js 工作台与 Java 联调

默认打开 `http://127.0.0.1:58872`。第一次初始化和账号配置见 [README](../README.md)。Spring Boot 自带基础风险页，完整工作台通过独立的 Node 进程启动。

| 地址 | 当前能力 |
| --- | --- |
| `/java-research` | Java 风险任务、SSE、快照、来源与结果导出 |
| `/knowledge-graph` | Java 公告采集、正文、Neo4j、证据审核和知识问答 |
| `/strategy-platform` | 保留入口；回测尚未迁入 Java 版 |
| `/`、`/research-reports`、`/business-knowledge`、`/skills`、`/eval-platform`、`/ops-platform` | 保留工作台页面；旧通用行情和报告链路未迁入 |

浏览器访问 Next.js 的 `/api/java/*`，同源代理通过白名单转发到 Spring Boot。Better Auth 会话与 Java 会话独立；只有本机配置的开发账号会映射到 Java 身份。Java 项目授权、CSRF、幂等键及 SSE 游标仍有效。Java 重启后需要重新连接，任务和结果由 PostgreSQL 保存。

工作台使用 Prisma 专用网页库；已有账号保持不变。已有工作台启动时不会自动导入另一版本的用户、项目与历史记录。Java 主库、网页库、Redis 和 Neo4j 的配置见 [运维](Java后端运维.md)。

```powershell
.\scripts\start-backend.ps1 -Demo
# 另一个终端
.\scripts\start-frontend.ps1
```
